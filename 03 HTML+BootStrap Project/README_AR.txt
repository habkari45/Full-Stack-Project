أكاديمية الويب الحديثة
======================
مشروع متعدد الصفحات مبني باستخدام HTML وCSS وBootstrap.

هيكل المشروع
------------
index/
courses/
dashboard/
profile/
settings/
subscribe/
search/
contact/
assets/images/
style.css

التشغيل
-------
افتح مجلد المشروع بالكامل في VS Code، ثم افتح index.html الموجود في الجذر
وشغّله بواسطة Live Server.

ملاحظات
-------
- جميع الصفحات مترابطة بروابط نسبية.
- ملف style.css موجود في جذر المشروع، والصفحات الداخلية مرتبطة به باستخدام ../style.css
- التصميم متجاوب مع أحجام الشاشات المختلفة.
- تم استخدام مكونات Bootstrap بشكل متناسق داخل المحتوى.
- الصورة الشخصية محفوظة محلياً داخل assets/images.
